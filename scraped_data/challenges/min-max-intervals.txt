PROBLEM STATEMENT:
Даден ви е масив с $N$ цели положителни числа: $A_0, A_1, ..., A_{N - 1}$ и цялото число $K$. ***MinMax*** интервал ще наричаме последователност от елементи на масива, такава че разликата между минималния и максималния измежду тях е най-много K. По-формално казано:

$MinMaxIntervals = \{A_i, ..., A_j | 0 \leq i \leq j < N \& max(A_i, ..., A_j) - min(A_i, ..., A_j) \leq K\}$

Намерете броят на ***MinMax*** интервалите в масива $A$ ($|MinMaxIntervals|$).

INPUT FORMAT:
На първият ред се въвеждат числата $N$ и $К$.

Следват $N$ числа - елементите на масива $A$: $A_0, A_1, ..., A_{N - 1}$.

CONSTRAINTS:
$0 \leq N \leq 2 \times 10^6$

$0 \leq K \leq 2 \times 10^6$

$0 \leq A_i \leq 2 \times 10^6$

OUTPUT FORMAT:
Изведете едно число - броя на ***MinMax*** интервалите в масива $A$.

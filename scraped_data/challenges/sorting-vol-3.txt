PROBLEM STATEMENT:
Сортирайте във възходящ ред масив от числа. Масивът е със зададена дължина. Масивът е почти сортиран (не повече от 2% от елементите му не са си на местата).

INPUT FORMAT:
На първия ред на стандартния вход се чете числото `n`. 

На вторият ред на стандартния вход се прочитат `n` числа - `a1, a2, ..., an`.

CONSTRAINTS:
`1 <= n <= 1000000`

`-1000000 <= a1, a2, ..., an <= 1000000`

OUTPUT FORMAT:
На един ред, разделени с интервал изведете числата `a1, a2,... an` в сортиран ред.

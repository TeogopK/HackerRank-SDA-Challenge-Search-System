PROBLEM STATEMENT:
Дадени са ви $N$ цели числа $a_0, ..., a_{N - 1}$, и цяло число $d$. Намерете сумата от минималните елементи на всички подмасиви с дължина $d$:

- $\displaystyle \sum_{i = 0}^{N - d} \min(a_i, a_{i + 1}, ..., a_{i + d - 1})$.

INPUT FORMAT:
Първият ред на стандартния вход съдържа две цели числа $N$ и $d$ - броя на числата и дължината на подмасивите.

Следват $N$ на брой цели числа - стойностите на $a_0, ..., a_{N - 1}$.

CONSTRAINTS:
$ 0 \leq N \leq 10^6$

$ 0 \leq d \leq N$

$ -10^9 \leq a_i \leq 10^9$

OUTPUT FORMAT:
Изведете едно цяло число - търсената сума.
